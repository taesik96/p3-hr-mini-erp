# P3 다온정밀(가상) HR 미니 ERP

중소 제조업용 인사·근태·급여 미니 ERP. 회계·생산·재고는 다루지 않는다.
설계 기준은 [기획서 v0.1](docs/01_기획서_v0.1.md), 현업 검증은 [인터뷰 질문지](docs/02_현업인터뷰_질문지.md).

Streamlit + SQLite. 가상 회사·가상 인물 데이터만 쓴다.

## 실행

```bash
pip install -r requirements.txt
```

```bash
streamlit run app.py
```

테스트 (pytest 필요, 임시 DB를 따로 만들어 쓰므로 `data/erp.db`는 건드리지 않음):

```bash
python -m pytest
```

처음 켜면 `data/erp.db`를 만들고 샘플 데이터를 채운 뒤 **9월 근태 확정(S09)과 급여 저장(S11, 작성중)까지** 해 둔다. 처음 보는 사람이 S11~S14 결과를 바로 볼 수 있게 하려는 것이다. 사이드바의 **샘플 데이터 초기화**를 누르면 이 상태로 돌아간다. Streamlit Cloud는 재시작하면 파일이 지워지는데, 그때도 같은 상태로 다시 만들어진다.

## 샘플 데이터

가상 회사: 자동차 부품 가공, 재직 40명(생산직 30 · 관리직 10) + 8월 말 퇴사자 1명. 생산직은 가공팀·조립팀 A조/B조가 한 주 단위로 주간조(08~19시)와 야간조(20~07시)를 바꾼다.

손계산 검증에 쓰도록 **까다로운 경우를 일부러 넣어 두었다.**

| 사례 | 확인할 규칙 |
|---|---|
| 9/12(토) 조립팀 B조 주간 특근 — 휴무일 근로 | R2 연장, R5 주 52시간 |
| 9/20(일) 가공팀 A조 2명 10시간 특근 — 주휴일 근로 | R3 휴일 8시간 이내·초과 |
| 9/24(목, 추석 연휴) 가공팀 B조 6명 특근 | R3 휴일 |
| 9/23(수) 밤 야간조가 9/24 공휴일 아침까지 근무 | R3·R4 자정 넘는 휴일 |
| 야간조 05~06시 — 연장과 야간이 겹침 | R2·R4 각각 가산 |
| 주 12시간 단시간 사무보조 | R6 주휴, R7 연차 제외 |
| 2026년 시급 갱신이 빠진 생산직 1명 | R8 최저임금 |
| 9월 중도 입사자, 3월 입사자(1년 미만) | R7 월 단위 연차 |
| 휴가 없이 하루 빠진 1명 | R6 주휴, R7 출근율 |

요율표 값(최저시급, 4대보험)은 언론 보도로 교차 확인만 했다. 급여 계산 전에 공식 고시 원문과 대조해야 한다 (S01에 경고 표시).

## 한 달 돌려 보기 (10월)

1. **S07** 대상 월 2026년 10월 → 자동 생성 → 근무표 저장. 기본 패턴은 8/31 주에 A조 주간, 1주마다 교대
2. **S07** 특근·근무 변경 → 휴일에 근무조를 넣으면 특근
3. **S08** 엑셀 업로드 → `docs/samples/2026-10_출퇴근_업로드예시.xlsx` → 정상 78건 반영, 오류 5건은 사유와 함께 걸러짐
4. **S09** 대상 월 2026년 10월 → 집계 확인 → 확정

S08 검사 항목: 없는 사번, 근무일·시각 형식, 근무표가 없거나 근무가 없는 날, 출근~퇴근 0시간 이하 또는 20시간 초과, 출근 날짜 ≠ 근무일, 파일 안 중복. 같은 사번·근무일이 이미 있으면 '덮어쓰기'로 표시한다. 오류 줄은 넣지 않고 따로 내려받아 고칠 수 있다.

출퇴근 기록이 있는 달은 근무표를 통째로 다시 만들 수 없다(기록과 어긋나므로). 그런 달은 S07 특근·근무 변경으로 한 칸씩 고친다.

## 근태 집계 (S09) 계산 기준

| 구분 | 기준 | 근거 |
|---|---|---|
| 연장 | 하루 8시간 또는 주 40시간(월~일)을 넘는 실근로 | 제50조, 제56조 제1항 |
| 휴일 | 주휴일·공휴일에 한 근로. 날짜는 0시에 바뀜. 8시간까지 50%, 넘는 부분 100% | 제55조, 제56조 제2항 |
| 야간 | 22시~06시 근로. 연장·휴일과 겹치면 각각 가산 | 제56조 제3항 |
| 주 52시간 | 휴일근로까지 더한 1주 총근로가 52시간을 넘으면 경고 | 제53조 제1항, 제2조 제1항 제7호 |
| 자정 넘는 근무 | 시작한 날의 근무로 묶고, 0시 이후가 공휴일이면 그 시간은 휴일근로 | 행정해석 **[원문 확인 필요]** |
| 반차·연차 | 실제 일한 시간이 아니라 주 40시간 계산에 넣지 않음 | 행정해석 **[원문 확인 필요]** |
| 조기 출근 | 근로로 인정하지 않음 | 회사 기준 — 인터뷰로 확정 (S09에서 바꿔 볼 수 있음) |
| 잔업 | 근무 종료 후 30분 이상 남았으면 퇴근 시각까지 분 단위로 인정 | 회사 기준 — 인터뷰로 확정 (S09에서 바꿔 볼 수 있음) |

모든 시간은 분 단위로 계산하고 반올림하지 않는다. 달 경계에 걸친 주(예: 9/28~10/4)는 앞뒤 달 기록까지 이어서 센다. 기록이 아예 없는 날짜가 섞인 주는 '부분 주'로 표시한다.

## 급여 계산 (S11) 계산 기준

S09에서 근태를 **확정한 달만** 계산한다. 금액은 분수로 끝까지 정확히 계산하고 마지막에만 끝수를 처리한다.

| 항목 | 계산 | 근거·기준 |
|---|---|---|
| 통상시급 | 월급제 (기본급 + 직책수당 + 식대) ÷ 209 · 시급제 시급 + (직책수당 + 식대) ÷ 209 | 시행령 제6조. 식대 포함은 회사 설정 (S03) |
| 기본급 | 월급제 월 기본급 · 시급제 (기본 근로 + 유급휴가 + 평일 공휴일) × 시급 | 토·일과 겹친 공휴일 미지급 [행정해석 — 원문 확인 필요] |
| 연장 · 휴일 · 야간 | 시간 × 통상시급 × 1.5 · (8시간까지 1.5, 초과 2.0) · 0.5(가산분) | 제56조 |
| 주휴수당 | 시급제만: 개근한 주 × 8시간 × 시급. 월급제는 월급에 포함 | 제55조, 시행령 제30조 |
| 월급제 결근 | (결근일 + 주휴 못 받는 주) × 기본급 ÷ 209 × 8 공제 | 회사 기준 — 인터뷰 확인 |
| 월 중 입사·퇴사 | 고정급을 달력 날짜로 일할 | 회사 기준 |
| 4대보험 | 과세 급여(식대 20만 원 제외)를 보수월액으로 보고 요율 적용, 10원 미만 절사. 월 중 입사자는 국민연금·건강 다음 달부터, 월 소정 60시간 미만은 제외 | **단순화** — 실무는 신고한 보수월액 기준 [원문 확인 필요] |
| 최저임금 | 매월 고정 지급하는 수당까지 넣은 환산 시급으로 비교 | 최저임금법 제6조 제4항 [원문 확인 필요] |
| 소득세 | 간이세액표에서 (과세 급여, 공제대상가족 수)로 찾음 → 8~20세 자녀 공제 → × 원천징수 비율(80·100·120%) → 10원 미만 절사. 지방소득세는 10% | 소득세법 시행령 별표 2 (2026.2.27 개정, 3/1 지급분부터). 홈택스 계산기와 13건 대조 일치 |
| 끝수 | 지급 원 미만 올림, 결근 공제 원 미만 절사 | 근로자에게 불리하지 않게 |

검증 사원 10명 (S11 "검증 추천"): 월급제 야근 · 월급제 결근 · 시급제 특근·휴가 없음 · 토요일 특근 · 일요일 특근 · 추석 특근 · 연차 사용 · 9/14 중도 입사 · 단시간 · 시급 갱신 누락.

## 소득세 (R9)

- **원천징수 정보:** 사원마다 공제대상가족 수(본인·배우자 각 1명 포함), 그중 8~20세 자녀 수, 원천징수 비율(80·100·120%). S04 인사카드에서 고친다. 샘플 값은 가상이고, 비율 120%(부장)·80%(차장)를 고른 사람을 한 명씩 넣었다.
- **계산:** S11의 "⑥ 소득세"에서 간이세액표의 해당 줄을 보여 주고 이 사원의 가족 수 칸을 노랗게 표시한다. 소득세 줄의 계산 근거에 표 구간 → 세액 → 자녀 공제 → 비율 → 절사가 한 줄로 들어간다.
- **표 밖 규칙:** 표 최저 구간(770천원) 미만 0원, 가족 11명 초과, 월급여 1천만 원 초과 계산식 6구간 (`erp/rules.py`).
- **검증 추천:** V11 자녀 3명 공제, V12 원천징수 비율 80%. V01(부장)은 120%.
- **표 출처:** `erp/tax/README.md` — 받은 주소, 날짜, SHA-256, 추출 방법, 추출 뒤 확인한 것.
- **홈택스 대조 (2026-10-29):** 홈택스 간이세액표 화면의 예시 표·자녀 공제 금액, 계산기 13건 × 80·100·120%가 모두 같았다. 월급여 1천만 원 초과에서 10원 차이가 나던 끝수 순서(100% 세액을 먼저 절사한 뒤 비율 적용)는 홈택스에 맞춰 고쳤다. 13건은 `tests/test_incometax.py`에 고정했다.

## 급여대장·마감 (S12) · 임금명세서 (S13)

**흐름:** S09 근태 확정 → S11 계산·저장(작성중) → S12 점검·확정(마감) → S13 명세서

- **확정 전 점검:** 저장한 값과 지금 계산을 줄 단위로 비교한다. 저장 뒤 근태 재확정·임금 변경·원천징수 정보 변경으로 달라진 줄이 있거나 최저임금 미달이 있으면 확정 버튼이 막힌다.
- **마감 잠금:** 확정된 회차의 급여 상세는 DB 트리거가 추가·수정·삭제를 거부한다. S12의 "금액 1원 바꿔 보기"로 직접 시험할 수 있고, S11에서도 다시 저장할 수 없다. 확정 취소는 가능하지만 실무에 필요한 권한·사유 기록은 이번 범위 밖이다.
- **급여대장 엑셀:** 시트 1 급여대장(사원 × 항목, 합계 줄), 시트 2 항목별 계산 근거.
- **임금명세서:** 근로자 정보, 근로시간(기본·연장·야간·휴일 8시간 이내/초과), 지급 항목별 금액과 **계산 방법**, 공제 항목별 금액, 총액, 실지급액. 확정 전이면 "확정 전 (작성중)"이 붙는다. 사원 한 명 PDF와 전 직원 PDF(1명당 1장)를 내려받을 수 있다.
- **법정 기재사항 (R10):** 근로기준법 제48조 제2항, 시행령 제27조의2의 6가지를 S13 점검표에 대응시켰다 [원문 확인 필요]. 생년월일은 저장하지 않아 사번으로 근로자를 특정한다.
- **PDF 글꼴:** 이 PC는 맑은 고딕, Streamlit Cloud는 `packages.txt`의 `fonts-nanum`(나눔고딕)을 쓴다.

## 인사 대시보드 (S14)

가장 최근 급여 회차와 그달 확정 근태를 모은다. 숫자는 모두 다른 화면에서 저장·확정한 값이고 새로 계산하지 않는다.

- **핵심 숫자:** 급여 받은 인원, 인건비 총액, 1인당 평균, 가산수당 비중, 연장+휴일 근로 합계, 주 52시간 초과(인원·건수)
- **부서별 인건비 구성:** 기본급 · 고정수당 · 가산수당 · 주휴수당 누적 막대 + 표 보기
- **연장+휴일 근로 상위 10명**, **주별 총근로 분포**(점 하나 = 한 사람의 한 주, 점선 = 52시간) + 52시간 초과 목록
- **인원 현황:** 부서별 인원, 근속연수 분포
- 색은 검증한 4색 순서(파랑·주황·청록·노랑)로만 쓰고, 52시간 초과는 빨강에 ⚠ 표시와 목록을 같이 둔다

## 배포 (GitHub → Streamlit Cloud)

P1·P2와 같은 방식이다. 로컬 git 저장소(`main` 브랜치)에 첫 커밋까지 해 두었다. GitHub 저장소는 아직 없다.

1. **GitHub 저장소 만들기** — github.com/new에서 `p3-hr-mini-erp`(P1·P2와 같은 `taesik96` 계정), Public, README·.gitignore 추가 없이 만든다. GitHub Desktop을 쓰면 *File → Add local repository*로 이 폴더를 고른 뒤 *Publish repository*.
2. **푸시** — 커밋은 되어 있다. 터미널이면:
   ```bash
   git remote add origin https://github.com/taesik96/p3-hr-mini-erp.git
   ```
   ```bash
   git push -u origin main
   ```
3. **테스트 확인** — 저장소의 *Actions* 탭에서 `tests`가 초록색인지 본다. 이 PC에는 Python 3.14만 있어서 3.12 확인은 여기서 처음 된다.
4. **Streamlit Cloud** — share.streamlit.io → *Create app* → 저장소 `taesik96/p3-hr-mini-erp`, 브랜치 `main`, 파일 `app.py`. *Advanced settings*에서 **Python 3.12** (pandas 3은 3.11 이상 필요). 주소는 P1·P2처럼 `taesik-hr-mini-erp` 정도로.
5. **배포 뒤 확인** — 홈의 "5분 둘러보기" 링크 5개, S13 명세서 PDF의 한글(나눔고딕이 깔렸는지), 앱 재시작 뒤에도 데모 상태로 다시 만들어지는지.

올라가지 않는 것: `data/`(샘플 DB, 앱이 만듦), `.claude/`(이 PC의 미리보기 설정), 캐시.
