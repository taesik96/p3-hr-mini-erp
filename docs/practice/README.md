# 1단계 진행 현황 — 기초 실무 한 바퀴

업무마다 **손으로 한 번, 시스템으로 한 번, 대조 기록**이 남으면 체크한다. 체크는 태식이 직접 한다.

전체 계획은 [`../03_실무프로젝트_계획.md`](../03_실무프로젝트_계획.md).

## 1주차 — 미뤄둔 검증 닫기

새 기능보다 먼저다.

- [ ] S09 "사례별 검증" 근태 10건 손계산 → 시스템과 대조
- [ ] 다른 칸이 있으면 어느 쪽이 틀렸는지 판정하고 규칙 또는 손계산을 고침
- [ ] 맞은 값을 `tests/test_rules.py`에 기대값으로 고정
- [ ] S11 "검증 추천" 사원 손계산 → 시스템과 대조
- [ ] 맞은 값을 `tests/test_payroll.py`에 기대값으로 추가
- [ ] 요율표(최저시급, 4대보험)를 공식 고시 원문과 대조하고 S01의 경고를 해제
- [ ] 기획서 §7 계산 규칙의 "원문 대조" 칸 체크

남는 것: 손계산 대조표, 고정된 테스트

- [ ] S11 급여 계산, 최저임금 미달 사원 처리

- [ ] S13 명세서 PDF, 법정 기재사항 점검표 확인
- [ ] [`월마감_체크리스트.md`](월마감_체크리스트.md)를 내 말로 고쳐 쓰기

## 3주차 — 입사 처리, 발령, 연차

입력 화면이 필요하다 (지금은 조회만 됨).

- [ ] S04 사원 등록 화면 추가 → 가상 신입 1명 직접 등록
- [ ] S06 임금 계약 등록 → 신입의 임금 계약 입력
- [ ] S05 발령 등록 → 승진 1건, 전보 1건
- [ ] 근로계약서: 고용노동부 표준근로계약서를 내려받아 손으로 한 장 작성 → 시스템 출력본과 비교
- [ ] 신입이 11월 근무표와 급여까지 이어지는지 확인 (월 중 입사 일할)
- [ ] S10 휴가 신청과 승인 → 연차, 반차 각 1건
- [ ] 연차 발생을 손으로 계산 (1년 미만, 1년 이상, 3년 이상 각 1명) → 시스템과 대조
- [ ] 연차사용촉진 통지서 한 장 작성 **[절차와 시기는 원문 확인 필요]**
- [ ] AX 지도에 "입사 처리", "인사정보와 발령", "연차" 태스크 분해

남는 것: 입사 서류 묶음, 연차 대조 기록

## 4주차 — 4대보험

- [ ] 4대사회보험 정보연계센터에서 취득 신고서 서식을 내려받아 3주차 신입으로 연습 작성 (제출하지 않음)
- [ ] 신고 기한을 공단 안내로 확인해 적어 두기
- [ ] S11의 4대보험 공제를 "신고한 보수월액" 기준으로 고치기 (지금은 단순화)
- [ ] 공단 모의계산기와 5명 대조
- [ ] 취득·상실 대상자 목록 화면 추가 (그달 입사자·퇴사자)
- [ ] 보수총액 신고가 무엇이고 언제 하는지 정리 **[올해 기준 확인 필요]**
- [ ] AX 지도에 "4대보험" 태스크 분해

남는 것: 신고서 연습본, 모의계산기 대조표

## 5주차 — 급여 세금

- [ ] 월별 원천징수 집계표 추가 (인원, 총지급액, 소득세, 지방소득세)
- [ ] 원천징수이행상황신고서 서식을 내려받아 9월분으로 연습 작성 (제출하지 않음)
- [ ] 간이지급명세서가 무엇이고 언제 내는지 정리 **[올해 기준 확인 필요]**
- [ ] 연말정산: 가상 사원 1명으로 흐름 따라가기 (자료 수집 → 공제 → 정산 세액 → 2월 급여 반영). 시스템에는 넣지 않음
- [ ] AX 지도에 "급여 세금" 태스크 분해

남는 것: 집계표, 연말정산 흐름 메모

## 6주차 — 퇴사 처리와 나머지

- [ ] 퇴직금 정산 추가 → 평균임금과 퇴직금을 손으로 계산 (3명) → 고용노동부 퇴직금 계산기와 대조

- [ ] 상실 신고서 서식으로 연습 작성 (제출하지 않음)
- [ ] 경력증명서 출력
- [ ] 퇴사 체크리스트 작성
- [ ] 채용 운영: 가상 채용 1건의 공고문, 지원자 정리표, 면접 일정표, 합격·불합격 통보문을 서류로 작성
- [ ] 법정의무교육: 어떤 교육이 의무인지 정리하고 이수 대장 양식 작성 **[원문 확인 필요]**
- [ ] AX 지도 완성 (모든 업무)

남는 것: 퇴사 서류 묶음, 완성된 AX 지도
