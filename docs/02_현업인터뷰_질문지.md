# 현업 인사담당자 인터뷰 질문지 (30분)

> ✅ 핵심 결론
> → 목적은 하나다. **실제 회사의 월 마감(근태 → 급여 → 지급) 흐름을 듣고, 기획서 §9의 미정 항목 9개를 정한다.**
> → 제조업 담당자가 가장 좋지만, 다른 업종 담당자에게도 그대로 쓸 수 있다. 업종이 다르면 A-1, C-1만 바꿔 묻는다.

**인터뷰 전 안내 멘트**
"HR 포트폴리오로 중소 제조업용 인사·급여 프로그램을 만들고 있어요. 실제 업무가 어떻게 돌아가는지 30분만 여쭤봐도 될까요? 회사 이름이나 직원 정보는 필요 없고, 일하는 순서만 알려 주시면 돼요."

**지킬 것**
- 실제 직원 급여 자료, 명세서, 엑셀 파일은 받지 않는다. (개인정보)
- 포트폴리오에 "현업 인사담당자 인터뷰 반영"이라고 써도 되는지 마지막에 묻는다.

---

## A. 회사와 시스템 (5분)

| # | 질문 | 왜 묻나 |
|---|---|---|
| A-1 | 업종과 대략적인 인원은요? 생산직과 사무직 비율은요? | 가상 회사 설정 검증 |
| A-2 | 인사·급여는 어떤 프로그램으로 처리하세요? (더존, SAP, 엑셀, 세무사 사무실 등) | 실제로 많이 쓰는 도구 파악 |
| A-3 | 출퇴근은 어떻게 기록하나요? (지문, 카드, 앱, 수기) 그 기록이 급여 프로그램으로 어떻게 넘어가요? | 기획서 §9-3, S08 업로드 양식 |

## B. 월 마감 흐름 (10분)

| # | 질문 | 왜 묻나 |
|---|---|---|
| B-1 | 근태 마감부터 급여 지급까지 순서대로 말씀해 주세요. 각 단계는 대략 며칠에 하세요? | 화면 순서와 마감 설계 |
| B-2 | 그중 시간이 제일 오래 걸리는 단계는 어디예요? | 시스템이 줄여 줄 지점 |
| B-3 | 급여를 확정한 뒤에 고쳐야 했던 경우가 있나요? 그때 어떻게 처리하세요? | 마감 잠금·재계산 설계 |

## C. 규칙과 예외 (10분)

| # | 질문 | 왜 묻나 |
|---|---|---|
| C-1 | 교대 형태는 어떻게 돼요? (주야 2교대, 3조 2교대, 3교대 등) 한 조가 몇 시간 일해요? | 기획서 §9-1, 근무조 정의 |
| C-2 | 연차는 입사일 기준이에요, 회계연도 기준이에요? | 기획서 §9-2, R7 |
| C-3 | 연장·야간수당은 실제 시간으로 계산하세요, 고정으로 주세요? (포괄임금) | 기획서 §9-5 |
| C-4 | 생산직 연장·야간수당 비과세 처리를 하세요? | 기획서 §9-4, R9 |
| C-5 | 직원들이 급여 관련해서 가장 자주 묻는 건 뭐예요? | 명세서(S13)에 보여 줄 정보 |
| C-6 | 근무 시작 전에 일찍 온 시간, 끝나고 조금 늦게 찍은 퇴근은 어떻게 처리하세요? 잔업은 미리 신청·승인을 받나요? | 기획서 §9-6·7, S09 계산 기준 |
| C-7 | 월급제가 결근하거나 월 중간에 입사하면 급여를 어떻게 계산하세요? 4대보험은 신고한 보수월액으로 떼세요? | 기획서 §9-8·9, S11 계산 기준 |

## D. 화면 피드백 (5분)
