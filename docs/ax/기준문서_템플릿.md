# 기준 문서 3종

AI에게 "알아서 해 줘"라고 하면 놓치는 것이 많다. 무엇을 보고 어떻게 판단할지를 먼저 글로 정한다. 과제마다 이 파일을 복사해 세 부분을 채운다.

초안은 태식이 쓰고, Claude는 애매한 표현과 빠진 경우를 짚는다.

---

## 1. 점검표 — 무엇을 확인할지

항목 하나는 "이 자료에서 이것을 하면 이렇게 나와야 한다" 한 줄이다.

| ID | 대상 | 입력·조작 | 기대 결과 | 실제 결과 | 판정 |
|---|---|---|---|---|---|
| T-001 | | | | | 통과 / 실패 / 판단 불가 |

- 항목은 순서대로, 각 항목은 한 번만 실행한다.
- 기대 결과는 사람이 읽어도 통과와 실패가 갈리게 쓴다. "적절해야 한다" 같은 말은 쓰지 않는다.

## 2. 실행 프롬프트 — 어떻게 실행할지

AI에게 그대로 넣을 지시문이다. 다음 네 가지가 들어가야 한다.

```
[하는 일]
(이 작업이 무엇이고 왜 하는지 두세 문장. 결과를 누가 어디에 쓰는지.)

[순서]
(점검표 항목을 어떤 순서로, 무엇을 열고 무엇을 비교하는지.)

[판정 기준]
- 실패는 기대 결과와 다른 점이 확인될 때만.
- 확인할 수 없으면 '판단 불가'로 두고 이유를 적는다.
- (과제에 맞는 기준을 더 적는다.)

[멈추고 사람에게 알릴 때]
- (돈, 계약, 개인정보, 권한 요청이 걸린 상황을 구체적으로 적는다.)
```

## 3. 기록 가이드 — 어떻게 남기고 비교할지

사람이 할 때와 AI가 할 때 같은 양식으로 남긴다. 양식이 다르면 비교할 수 없다.

- 결과를 적는 곳: (파일 이름, 시트 이름)
- 회차마다 새 탭 또는 새 파일로 쌓는다. 덮어쓰지 않는다.
- 실패 항목에는 증거를 붙인다: (화면 캡처, 해당 줄 번호 등)
- 사람이 끼어든 횟수와 이유를 적는다.
- 시간은 시작과 끝 시각을 적어 계산한다. 어림으로 적지 않는다.
