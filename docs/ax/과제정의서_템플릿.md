## 6. 과제 선정 점검

다섯 가지를 모두 만족해야 진행한다.

- [ ] 매주 또는 매달 반복된다 (회차를 여러 번 돌릴 수 있다)
- [ ] 잘됐는지의 기준을 글로 적을 수 있다
- [ ] 지금 방식의 시간과 실수를 잴 수 있다
- [ ] 사람이 마지막에 확인하는 단계를 둘 수 있다 (틀려도 돈·안전 사고로 바로 이어지지 않는다)
- [ ] 회사가 자료 사용을 허락했다
- [ ] 근로계약서·급여·4대보험 신고 같은 인사 서류의 작성이나 대행이 아니다 (`CLAUDE.md`의 범위)
