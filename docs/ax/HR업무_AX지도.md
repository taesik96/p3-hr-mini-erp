# HR 업무 AX 지도

인사운영 업무를 태스크로 쪼개고, 태스크마다 AI가 어디까지 할 수 있는지 나눈 지도다. **직접 해 본 업무만 채운다.** 해 보지 않고 채운 칸은 추측이라 면접에서 설명할 수 없다.

## 분류 기준

| 분류 | 뜻 | 이런 태스크 |
|---|---|---|
| A. AI가 수행 | 규칙이 분명하고 결과를 기계적으로 검증할 수 있다 | 옮겨 적기, 형식 검사, 대조, 날짜 계산 |
| B. AI 초안, 사람 확인 | AI가 만들고 사람이 읽고 고친다 | 통지문 초안, 요약, 예외 후보 표시 |
| C. 사람이 판단과 책임 | 법적 판단, 당사자에게 설명해야 하는 결정, 관계가 걸린 일 | 징계, 해고, 임금 결정, 분쟁 대응 |

태스크 하나를 놓고 다음 네 가지를 묻는다. 하나라도 강하게 해당하면 C다.

1. 틀렸을 때 근로자의 임금이나 지위에 바로 영향을 주는가
2. 법 해석이 갈리는가
3. 당사자에게 이유를 설명해야 하는가
4. 숫자나 문장만으로 판단하기 어려운가

분류 옆에 **근거**를 적는다. 노동법 지식이 쓰이는 칸이다. "왜 이 태스크는 사람이 해야 하는가"에 조문이나 실무 이유를 댈 수 있어야 한다.

## 지도를 다 채운 뒤

- A가 몰려 있는 업무가 자동화 1순위다. 2단계의 예행연습과 3단계 과제 후보를 여기서 고른다.
- C로 분류한 태스크 목록은 "AI를 쓰더라도 인사담당자가 남아야 하는 이유"다. 면접에서 그대로 쓸 수 있다.
- 현업 인터뷰에서 이 지도를 보여 주고 틀린 곳을 물어본다. 고친 횟수를 기록한다.
