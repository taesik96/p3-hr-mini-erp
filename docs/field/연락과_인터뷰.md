# 소사업장 연락과 인터뷰

**실제 회사 이름, 담당자 이름, 연락처는 이 파일에 적지 않는다.** 연락 명단과 인터뷰 기록은 `private/` 폴더에 둔다 (저장소에 올라가지 않음). 이 파일은 양식과 원칙만 담는다.

## 한 번의 만남으로 두 가지를 한다

현업 인사·총무 담당자를 만나면 다음 두 가지를 같이 묻는다.

1. [`../02_현업인터뷰_질문지.md`](../02_현업인터뷰_질문지.md) — 월 마감 흐름, 기획서 §9의 미정 항목
2. 아래 "반복 업무 질문" — 3단계 과제 후보

## 누구에게

직원 10~50명의 제조, 건설, 설비, 유통 업체에서 사무 업무를 한두 명이 도맡는 곳. 이 범위는 가정이고 첫 인터뷰 몇 건으로 고친다.

연락 경로는 성공 가능성이 높은 순서로 쓴다.

1. 지인 소개
2. 링크드인 설문에 답한 현직자에게 울산 지역 소개 부탁
3. 지역 기관의 AI 관련 설명회와 교육
4. 콜드 메일과 전화

## 연락할 때 지킬 것

- 목적은 30분 인터뷰를 얻는 것 하나다.
- 솔직한 이유를 말한다. 취업을 준비하며 AI 업무 자동화 프로젝트를 하고 있고, 반복 업무 하나를 AI가 대신 하도록 만들어 보고 싶다.
- 비용을 받지 않는다. 대신 결과를 회사 이름을 가리고 포트폴리오에 쓰고 싶다고 처음에 말한다.
- 회사 자료는 허락한 범위에서만 쓴다고 말한다.
- 전문가, 컨설턴트, 자문, 진단 같은 말을 쓰지 않는다.
- 믿을 근거를 한 줄 넣는다. 배포된 미니 ERP 주소, 가상 회사로 해 본 사례.

메시지 초안은 Claude에게 회사 정보(업종, 인원, 연락 경로)를 주고 문자용 3문장, 메일용 6문장, 전화용 30초 대본으로 받는다.

## 반복 업무 질문

"AI로 자동화하고 싶은 업무가 있나요"라고 묻지 않는다. 지난주에 실제로 한 일을 묻는다.

1. 매주 또는 매달 똑같이 반복하는 일 중에 가장 시간이 걸리는 것은 무엇인가요.
2. 그 일을 할 때 어떤 파일과 프로그램을 열고, 어디서 어디로 옮겨 적으시나요.
3. 두 문서의 숫자가 맞는지, 빠진 항목이 없는지 대조하는 일이 있나요.
4. 바빠서 건너뛰거나 미루는 일이 있나요.
5. 새로 온 사람에게 가르치기 어려운 일은 무엇인가요.
6. 날짜를 놓쳐서 곤란했던 적이 있나요.
7. ChatGPT 같은 도구를 써 보셨나요. 써 봤다면 어디서 막히셨나요.
8. 그 일이 절반으로 줄면 그 시간에 무엇을 하고 싶으신가요.

## 인터뷰 기록 양식 (`private/`에 저장)

```
- 날짜 / 회사 기호 / 업종 / 인원 / 담당자 직무
- 포트폴리오에 써도 되는 범위: (회사 기호만 / 업종까지 / 불가)

[담당자가 한 말] — 그대로 인용
"..."
→ 한 줄 요약

[반복 업무 표]
| 업무 | 빈도 | 걸리는 시간 | 쓰는 파일 | 실수가 나는 지점 |
(담당자가 말하지 않은 숫자는 비워 둔다)

[내 해석] — 위와 섞지 않는다

[월 마감 흐름] — 인터뷰 질문지 B, C 답변
```

## 연락 현황 (숫자만)

회사 이름 없이 숫자만 여기에 적는다. 첫 10곳의 응답을 보고 목표치를 다시 잡는다.

| 주 | 연락한 곳 | 답이 온 곳 | 인터뷰 잡힌 곳 | 인터뷰 한 곳 |
|---|---|---|---|---|
| 1 | | | | |

4주가 지나도 인터뷰가 한 건도 잡히지 않으면 미래내일 일경험 프로젝트형 지원과 지역 기관 행사 참석으로 경로를 넓힌다.
